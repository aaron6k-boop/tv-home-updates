HYE TV (Tizen) - what's in this folder
======================================

TVHome-Tizen.wgt   TV Home with kids mode (on by default on this TV)
Jellyfin.wgt       Films and shows from your PC (if it downloaded)
Moonlight.wgt      Play PC games like Roblox with a controller (if it downloaded)
TizenBrew.wgt      Lets you add TizenTube for ad-free YouTube (if it downloaded)

1. On the HYE TV: Home > Apps, press 1 2 3 4 5 on the remote.
   Turn Developer Mode On, type your PC's IP address, OK, then restart the TV.
2. On the PC: install Apps2Samsung (free, github.com/Apps2Samsung/Apps2Samsung).
   Choose "Custom WGT" and pick each .wgt file in this folder, one at a time.
   Newer TVs ask you to sign in with a free Samsung account the first time.
3. Ad-free YouTube: open TizenBrew on the TV and add the module
   @foxreis/tizentube (TizenBrew > Module Manager > Add NPM module).
