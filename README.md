# TV Home

Latest version: **1.0.101** (Films from USB: subtitles found in Subs folders and with any capitals, old Windows subtitle files show accents properly, subtitle size option, Sound & subtitles shown whenever the controls are up)

## Install on an Android TV or Google TV (TCL, Sony, ...)

1. **[Download TV-Home-Installer.zip](https://github.com/aaron6k-boop/tv-home-updates/raw/main/TV-Home-Installer.zip)** on a Windows PC on the same Wi-Fi as the TV, and unzip it.
2. On the TV: Settings > System > About, press OK on *Build* 7 times. Then Settings > System > Developer options > turn on **USB debugging**.
3. On the PC: double-click **Install TV Home.exe** and press **Install**. If Windows says *Windows protected your PC*, click *More info*, then *Run anyway*. When the TV asks *Allow USB debugging?*, tick *Always allow* and press OK.
4. When it says *All done*, press Home on the TV remote.

Updates arrive by themselves: the TV shows **Update ready** at the top. Choose it, then **Install**.

To put everything back: open **Install TV Home.exe** and press **Undo**.
